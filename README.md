# zelos.dgx-proxmox-test-vm

Proxmox VM test target for the [`zelos.dgx`](https://github.com/kmechlin/zelos.dgx)
Ansible collection. Builds, snapshots, resets, and destroys a single DGX OS
VM with GPU passthrough as a repeatable baseline for `zelos.dgx` iteration.

v0.1.0 scaffold; full operator documentation in `docs/runbook.md` once the
initial scaffold lands on `develop`.
